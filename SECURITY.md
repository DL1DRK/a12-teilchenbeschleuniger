# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version bereitgestellt.

## Schwachstellen melden

Bitte Sicherheitsprobleme nicht als öffentliches GitHub-Issue melden. Nutzen Sie nach Möglichkeit GitHubs Funktion **Security → Report a vulnerability** im Repository. Falls diese Funktion nicht verfügbar ist, wenden Sie sich direkt an den Repository-Inhaber DL1DRK und nennen Sie:

- betroffene Version,
- nachvollziehbare Schritte,
- mögliche Auswirkungen,
- bereits bekannte Abhilfen.

Veröffentlichen Sie technische Details erst, nachdem eine korrigierte Version bereitsteht oder die Offenlegung abgestimmt wurde.

## Betriebshinweise

- Installation ausschließlich über HTTPS betreiben.
- Installer und Updater nach erfolgreicher Ausführung entfernen.
- SQLite-Datenordner regelmäßig sichern und nicht öffentlich zugänglich machen.
- Administratorrechte sparsam vergeben und individuelle Konten verwenden.
- PHP und das Webhosting aktuell halten.
